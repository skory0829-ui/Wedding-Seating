# Wedding Seating Chart

A private little web app for planning our wedding reception seating.

**Live app:** https://skory0829-ui.github.io/Wedding-Seating/

- Hosted via GitHub Pages (this repo). The page itself holds no guest data.
- Guest list + assignments live in the app's per-device storage and sync via a separate private data repo (configured in-app under **Setup - Sync across phones**).
- To update the app, edit `index.html` here and it redeploys automatically.
